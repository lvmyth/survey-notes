🔭 观测方法

等长法（平行四边形法）两端各垂直向下量取等于弧垂 f 的距离绑弛度板，视线与导线最低点相切即达标。

异长法两端量距 a≠b，视线相切时 f=(√a+√b)²/4；已知 f 与 a 可反求 b。

规则：填 a、b 求 f；或填 f、a 求 b（b 留空）。

📖 公式与说明

① 弧垂正算 抛物线： f = g·l² / (8·σ) (等高) 高差修正：f = g·l² / (8·σ·cosβ)，β=atan(h/l) 悬链线： f = (σ/g)·[cosh(g·l/(2σ)) − 1] (等高) ② 观测反算 等长法： a = b = f 异长法： f = (√a + √b)² / 4 角度法： β = atan( (h − 2f) / l ) ③ 温度-应力 状态方程：σ₁ − E·g₁²·l²/(24σ₁²) = σ₀ − E·g₀²·l²/(24σ₀²) − α·E·(t₁−t₀)
